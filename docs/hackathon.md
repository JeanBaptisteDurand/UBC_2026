# UBC 2026 hackathon: rules and tracks

Summary of the official hackathon guide (version of Oct 31, 2026).

## Timeline (CST)

| When | What |
|---|---|
| Sun Nov 8, 18:00 | Kickoff |
| Fri Nov 13, 12:00 | Build starts |
| Nov 16–19 | Solana and Circle workshops |
| Fri Nov 20, 12:00 | Submission deadline |
| Sat Nov 21 | Judging and finals in Austin (attendance required for any prize) |

## Tracks (one winner each, $2,000)

1. **Agentic Payments & AI**: execute onchain transactions or read the chain, on any chain (devnet/testnet is fine).
2. **DeFi & Onchain Apps**: deploy smart contracts on any chain.
3. **Consumer Apps**: interact with the blockchain in some way, with a working front end.

Each track is judged by a Solana judge, an Arc judge and a chain-neutral judge.

## Awards on top of the track

- **Best use of Arc**: $1,000 per track. Contracts or core logic on Arc (testnet OK), with the address and a "How this project uses Arc" README section.
- **Best use of Solana**: $1,500 per track. A project can win either Arc or Solana, not both.
- **Official UBC 2026 Hackathon Winner**: $2,500 / $1,000 / $500, open to every team.
- **Gemini Prediction Markets**: $2,500 / $1,000 / $500; the 1st place also pitches in the finals.
- **QuickNode Streams**: $500, at least one Stream with a filter and a destination, explained in the README.
- ElevenLabs and Grok Bot side prizes.

## Finals

Up to 13 teams: top 3 of each track, top 3 Official Winner, Gemini 1st. 5 min pitch + 2 min Q&A.

## What we must hand in

- [ ] Public repo with a clear README
- [ ] Demo video, 2 to 3 minutes
- [ ] Contract addresses (and the Arc section if we go for the Arc award)
- [ ] Submission form before Nov 20, 12:00 CST
